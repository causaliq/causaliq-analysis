    Plot¶

    plot ¶

    Plot charts from summarised experimental results.

    This module migrates and restructures the legacy experiments/plot.py module from the causaliq-discovery repository so that figures such as the variable-ordering CPDAG F1 chart can be replicated exactly from a summarise CSV output.

    Functions:

    • parse_properties –

      Parse chart property strings into a typed dictionary.

    • plot_degree_distribution –

      Plot node degree distributions for networks.

    • plot_scatter –

      Plot one or more scatter plots.

    • relplot –

      Plot a set of relational charts.

    • run_plot –

      Generate a chart from a summarise CSV output.

    parse_properties ¶

    parse_properties(properties: Optional[Union[str, List[str]]]) -> Dict[str, Any]

    Parse chart property strings into a typed dictionary.

    Each property is a string of the form <name>=<value> (e.g. "int.property=22"). Values are parsed as Python literals so "0.05" becomes a float, "[1, 2]" a list, "{'a': 1}" a dict and "True" a boolean.

    Parameters:

    • properties ¶
      (Optional[Union[str, List[str]]]) –

      list of property strings, a single string, or None.

    Returns:

    • Dict[str, Any] –

      Dictionary of parsed property names to typed values.

    Raises:

    • ValueError –

      If a property string is malformed.

    relplot ¶

    relplot(
    data: DataFrame,
    props: Dict[str, Any],
    plot_file: str,
    info: Optional[Dict[str, SubplotInfo]] = None,

    Plot a set of relational charts.

    Parameters:

      (DataFrame) –

      data in long form with the following columns: subplot (identifies the subplot), x_val (x values), y_var (y-variable on each subplot) and y_val (y values).

      optional extra information to print on the chart.

    Raises:

    • ValueError –

      If an unsupported subplot.kind is requested.

    run_plot ¶

    run_plot(
    input_csv: str,
    output: str,
    kind: str = "line",
    subplot: str = "",
    group: str = "",
    x: str = "",
    y: str = "",
    properties: Optional[Union[str, List[str]]] = None,
    log_fn: Optional[Callable[[str], None]] = None,
) -> Dict[str, Any]

    Generate a chart from a summarise CSV output.

    The input CSV contains one row per subplot, x value and group combination (as produced by the summarise action). The chart is generated using the migrated legacy plotting functions.

    Parameters:

    • input_csv ¶
      (str) –

      path of the input CSV file.

    • output ¶
      (str) –

      path of the output chart file (e.g. .png or .jpg).

    • kind ¶
      (str, default: 'line' ) –

      type of plot required, e.g. line or bar.

    • subplot ¶
      (str, default: '' ) –

      column name defining the subplot.

    • group ¶
      (str, default: '' ) –

      column name defining the groups shown in the legend.

    • x ¶
      (str, default: '' ) –

      column name providing the x-axis values.

    • y ¶
      (str, default: '' ) –

      column name providing the y-axis values.

    • properties ¶
      (Optional[Union[str, List[str]]], default: None ) –

      list of chart property strings in <name>=<value> format with Python literal values.

    • log_fn ¶
      (Optional[Callable[[str], None]], default: None ) –

      optional callback used to log progress messages.

    Returns:

    • Dict[str, Any] –

      Dictionary of metadata describing the chart generated.

    Raises:

    • ValueError –

      If the kind, columns or input file are invalid.
